FINJARVIS — PHONE INSTALL PACKAGE

This is a Progressive Web App (PWA) bundle. To install it on Android:
1. Upload these files to a HTTPS static host (GitHub Pages is a free option).
2. Open the hosted index.html link in Chrome on your phone.
3. Chrome menu (⋮) > Install app or Add to Home screen.
4. Launch FinJarvis from the new home-screen icon.

Important:
- Browser-based microphone and speech recognition work best in Chrome; allow microphone permission.
- Expense records are stored locally in that browser/device. They do not automatically sync between phone and computer.
- HTTPS hosting is required for install/offline caching and microphone permissions.
